2026 월드컵을 무대로, 사용자가 직접 감독이 되어 전술을 설계하고 선수를 배치하는 동적 전술 시뮬레이터. 실제 코칭 스태프의 부하관리·교체 판단을 데이터로 보조하고, 대표팀의 아쉬웠던 경기를 대체 역사로 다시 쓴다.

▶ 스토리보드 — 한눈에 보는 감독 경험

사용자가 화면에서 보는 순서대로: 상황 → 전술 → AI 코치 → 교체 → 대체 역사 → 데이터 한계.

1
상황 — 우리 팀이 1–2로 뒤진 채 조별리그 탈락 위기. “내가 감독이라면?”
2
전술 — 포메이션·슬라이더로 팀 형태를 직접 설계. 조작이 보드에 실시간 반영.
3
AI 코치 — 근거와 신뢰도를 함께 제시하고, 버튼 한 번으로 전술 즉시 반영.
4
교체 — 출전시간·체력 근거로 최적 교체를 제안. 스타 선수 투입도 원클릭.
5
대체 역사 — 전술을 반영한 재시뮬레이션으로 REAL vs YOUR 스코어를 비교.
6
데이터 한계 — 장면마다 사용/제외 데이터를 자막으로 명시해 과장 없는 투명성 확보.

02 ‘감독 경험’ 설계 의도

팬은 경기 결과를 소비할 뿐, 그 결과를 만든 전술적 의사결정 과정에는 개입할 수 없다. 본 서비스는 “내가 감독이었다면?”이라는 질문에 답을 주는 것을 목표로, 세 층위의 감독 경험을 설계했다.

지휘 (Command)

선발 배치·포메이션·전술 슬라이더로 팀의 형태를 직접 만든다. 조작이 즉시 보드에 반영돼 통제감을 준다.

판단 (Decide)

경기 중 체력·기세·상대 강점을 읽고 교체·전술을 결정한다. AI가 근거를 제시하되 최종 결정은 사용자.

책임 (Own)

선택의 결과가 승률·스코어·평점으로 돌아온다. 대체 역사로 “내 결정이 만든 결과”를 확인한다.

설계 원칙

  • 즉각적 피드백 — 모든 전술 조작은 보드·승률·대체역사에 실시간 반영되어 인과관계를 체감하게 한다.
  • 근거 우선 — AI 제안은 “무엇을·왜”를 신뢰도와 함께 제시(블랙박스 지양). 감독의 학습을 돕는다.
  • 실전 은유 — 부하관리·교체 타이밍 등 실제 코칭 스태프의 의사결정 언어를 그대로 차용한다.
  • 존중과 정직 — 특정 국가·선수를 비하하지 않고, 확정되지 않은 결과는 시나리오로 명시한다.
감정 훅 — 대표팀의 아쉬웠던 경기를 사용자가 감독이 되어 다시 설계·재시뮬레이션함으로써, 몰입과 재도전의 동기를 제공한다.

05 데이터 활용 방식

데이터 스키마 (StatsBomb 호환)

구조내용
Team / Player팀(색·코드·국문/영문명), 선수(등번호·역할·좌표·기량·체력·스타 여부)
MatchEvent분(minute)·팀(side)·유형(goal/shot/chance/corner/card/sub/whistle)·선수·xG·해설(한/영)
MatchData라인업·벤치·타임라인·실제 스코어·서사·데이터 출처(real/scenario)

활용 로직

  • 경기 엔진 — 타임라인을 특정 분까지 접어 스냅샷(스코어·xG·점유율·기세) 산출, 로지스틱 승률 곡선 생성.
  • 대체 역사 — 실제 xG 총합을 전술 계수로 보정 → 포아송 재시뮬레이션. 시드 고정으로 재현 가능.
  • 체력 모델 — 역할×전술 강도(압박·템포·라인) 기반 분당 소모율로 스태미나 계산.
  • 부하관리 분석 — 출전시간·체력 임계(45%) 도달 예상 시점·점수 상황을 종합해 교체 우선순위·최적 대체자 산출.

데이터 출처 & 확장

  • 실측: 2018·2022 월드컵 결승 이벤트 · 시나리오: 2026(태그 명시).
  • 외부 API·키 불필요(전량 내장) → 심사자가 키 없이 모든 기능 확인 가능(규정 부합).
  • StatsBomb 로더로 교체 시 UI 변경 없이 공식 데이터 연동 가능.
장면별 데이터 근거 자막 — 경기 화면은 현재 장면(상황·공격·득점·진행)마다 ‘✓ 사용 데이터’와 ‘⚠ 제외·한계(추정 대체 포함)’를 자막처럼 함께 표기한다. 심사자·시청자가 기능 장면과 데이터 근거·한계를 동시에 확인할 수 있어, 과장 없는 데이터 투명성을 보장한다.
